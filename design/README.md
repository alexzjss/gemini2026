# Telas do aluno

Protótipos das telas do aluno (1º ao 3º ano do EM), feitos no Claude Design.

Canvas: https://claude.ai/artifact/RDF5MEN661b4my1DWvR5pq

- `canvas.json`: índice do canvas (posição de cada tela)
- `M-*.dc.html` / `Main.dc.html`: telas mobile (390×844)
- `D-*.dc.html`: telas desktop (página fluida, 1440 de largura)

Os arquivos `.dc.html` são o formato do Claude Design e dependem do runtime do canvas pra renderizar.
Placeholders a substituir: `[nome do app]` e `[FAIXA SALARIAL · fonte oficial a definir]`.
O aluno, as rotinas e os mentores são ilustrativos.
